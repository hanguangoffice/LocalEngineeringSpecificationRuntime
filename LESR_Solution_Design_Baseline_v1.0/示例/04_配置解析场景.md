# 示例 04：配置解析场景

## 输入

```text
Baseline: BL-1.2
Variant: EU
Workspace: CHG-021
Operation: approve_revision
Target: REQ-COM-004
```

## 解析

1. BL-1.2 选择 REQ-COM-004@5；
2. Workspace 提供 Candidate @6；
3. EU Variant 启用 PROFILE-EU@2；
4. Deviation DEV-004 已过期；
5. approve_revision 使用 Candidate @6；
6. Rule Set 使用 Profile + Tailoring + EU Overlay；
7. 过期 Deviation 不生效；
8. 若 Profile 编译冲突，则 Effective Resolution = INDETERMINATE。

## 输出

包含 Selected Revision、Effective Rules、Excluded Rules、Active Deviations、Unknowns 和 Explanation Trace。
