# DD-010 规范模态与执行后果分离

- 状态：ACCEPTED；具体枚举 PROVISIONAL
- 决策：
  - Normative Modality、Applicability、Evaluation、Enforcement、Deviation Policy、Criticality 和 Priority 分离。
- 核心 Modality：
  OBLIGATION、PROHIBITION、PERMISSION、RECOMMENDATION、DISCOURAGEMENT、INFORMATIONAL。
- Enforcement：
  按具体 Operation 或 State Transition 映射，不由全局 severity 推断。
- Permission：
  只有通过明确 Exception、Authorization 或 Authority 关系才能覆盖 Prohibition。
- 冲突：
  无法解析时 Effective Model 为 INDETERMINATE，高风险正式操作暂停。
