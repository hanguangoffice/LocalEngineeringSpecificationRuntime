# LESR 术语表

| 术语 | 定义 |
|---|---|
| Logical Object | 跨 Revision 持续存在的语义主体 |
| Revision | 不可变的正式对象版本 |
| Working Copy | Change Workspace 内可修改候选 |
| Checkpoint | 可恢复的 Workspace 中间快照 |
| Human Key | 面向人类的工程编号 |
| Internal UID | 永久且无业务语义的内部身份 |
| Fragment | 与父 Revision 共同版本化的可寻址局部元素 |
| Profile | 定义 Kind、Facet、Relation、Rule、Workflow 等的规范包 |
| Effective Model | Profile、Tailoring、配置和 Deviation 的编译结果 |
| Rule Definition | 用户批准的规范规则 |
| Rule AST | 规则的规范化机器语义 |
| Applicability | 判断规则是否作用于目标的表达式 |
| Constraint | 对目标必须满足或不得满足的条件 |
| Evaluation Run | 某次规则检查活动 |
| Observation | 不可变的检查事实 |
| Issue | 对 Observation 的治理响应 |
| Enforcement Decision | 对具体 Operation 的允许或阻止决定 |
| Deviation | 对具体规则和作用域的批准偏离 |
| Relation Assertion | 版本化、有来源的关系声明 |
| Formal Trace Credit | 某关系是否满足正式追踪要求 |
| Evaluation Context | 解析对象、规则和操作的完整上下文 |
| Context Contract | 为 AI 任务生成的结构化上下文包 |
| Review Package | 审批所绑定的不可变变更材料 |
| Approval Attestation | 对准确 Review Package 和 Scope 的批准记录 |
| Semantic Transaction | 原子应用一组语义操作的事务 |
| Canonical State | Git Commit Tree 中的权威结构化状态 |
| Query Projection | 可由 Canonical State 重建的查询索引 |
| Baseline | 精确冻结对象、关系、规则和配置的快照 |
| Provenance | Entity 由哪些 Activity 和 Agent 产生的来源证明 |
| Audit | 系统操作时间线 |
