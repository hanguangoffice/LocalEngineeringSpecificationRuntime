# 07 AI 上下文与注意力模型

**决策成熟度：FOUNDATIONAL；摘要与模型适配 PROVISIONAL**

## 1. Context Contract

固定 Task Type、Target、Base Configuration、Change Workspace、Effective Model、Delegation Grant、Token Budget 和 Confidentiality Boundary。

---

## 2. Read Set

- Invariant；
- Mandatory；
- Conditional；
- Supporting；
- Background；
- Negative Context；
- Unknown/Indeterminate。

---

## 3. 对象粒度

默认返回原子对象 Manifest，不返回整个 Published Document。长对象通过 Fragment 精确展开。

正式强制文本不能只保留 AI 摘要。

---

## 4. Mandatory 来源

正式 Relation、Applicability、Profile Context Policy、当前操作、Core Safety Invariant、Effective Deviation、Baseline 和 Delegation Restriction。

---

## 5. 完整性状态

```text
complete_under_effective_model
incomplete_missing_relation
incomplete_unknown_scope
incomplete_index_projection
incomplete_budget_truncation
indeterminate_profile_conflict
blocked_by_confidentiality
```

---

## 6. Fragment

用于精确展示验收条件、代码位置、Evidence Anchor 和长对象局部读取。正式追踪长期依赖 Fragment 时，应建议 Promotion。

---

## 7. Delegation Context

每次 Draft 写操作必须知道 Grant、剩余范围、禁止操作、停止条件、Base Revision 和当前 Workspace Finding。

## 14. Context Contract 基线

Context Planner 必须使用明确 Evaluation Context，输出 Completeness、Negative Context、Selection Trace 和 Omitted Candidates。详细定义见 `07A_ContextContract完整性与渐进披露.md`。
