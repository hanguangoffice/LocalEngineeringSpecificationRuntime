# 15 开放问题与暂定决策表

## 1. 已接受的设计组

### 基础设施与权限

- Git 必须存在；
- 用户规范决定严格性；
- Scoped Delegation；
- AI 只连续修改 Working Copy；
- Markdown 不承担主要语义事实源。

### 对象与身份

- Core Class + Facet + Kind；
- Composite/Atomic/Fragment/Field；
- UID/Human Key/Alias；
- Logical Object/Revision；
- Observation/Issue；
- Process Definition/Activity；
- Relation Assertion。

### 生命周期与关系

- Maturity/Disposition/Membership；
- Maturity 与 Disposition 由不可变 Lifecycle Record 投影；
- Logical/Pinned/Fragment/External Binding；
- Core Relation Role；
- Formal Trace Credit；
- Baseline 固定准确版本；
- 不使用模糊 current。

### 规则

- Rule Definition/Evaluation/Observation/Decision 分离；
- Canonical Rule AST；
- 三值 Applicability；
- 静态类型与单位；
- 模态与 Enforcement 分离；
- Authority、Exception、Tailoring、Deviation 分离；
- Rule Compiler、Explanation Map、Fixtures；
- Profile 无任意执行代码。

### 配置与评审

- Evaluation Context；
- Effective Resolution；
- Partial Configuration 显式；
- Review Package；
- Approval Attestation；
- Re-review Trigger。

### 状态与事务

- Git Commit Tree 权威；
- Snapshot + Applied Change Record；
- Query Projection 可重建；
- Semantic Transaction；
- Git Ref 原子推进；
- Semantic Merge/Rebase。

### AI 与接口

- Context Contract；
- Mandatory Read Set 确定性；
- MCP 与领域解耦；
- Git/Audit/Provenance 分工。

---

## 2. 仅剩实现阶段开放项

| 主题 | 候选 |
|---|---|
| UID 格式 | UUIDv7 / ULID |
| Canonical 序列化 | JSON / YAML / JSON-LD / 混合 |
| Rule AST 序列化 | JSON Schema 定义的 JSON 或其他 |
| Rule Backend | 自定义 AST + JSON Schema；可选 SHACL/Rego |
| Query Projection | SQLite / RDF / 属性图 / 混合 |
| 中文全文检索 | FTS5 分词扩展 / 其他引擎 |
| Workspace Git | Branch / Ref / Commit / Pack |
| Applied Change 与 Commit | 一对一或批量 |
| MCP SDK | 稳定版或兼容候选版 |
| UI | 本地 Web / 桌面 / 混合 |
| 插件沙箱 | 进程隔离 / WASM / 受限运行时 |
| Provenance 格式 | 自定义结构 + PROV 映射 |
| 确认凭据 | 本地签名 / 一次性令牌 / 系统认证 |

这些内容必须通过原型决定，不属于继续扩展方案概念的问题。
