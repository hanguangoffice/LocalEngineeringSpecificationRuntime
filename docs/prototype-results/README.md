# LESR v1.0 prototype results

Each P1-P5 report is a versioned engineering decision record with the same
sections: Question, Hypothesis, Scope, Dataset, Alternatives, Measurements,
Results, Failure Modes, Decision, Reversal Cost, Code to Keep, Code to Delete,
and Open Issues.

Prototype code is disposable by default. A result may be moved into the
long-lived runtime only after its gate passes and the report explicitly marks
the code as reusable.
